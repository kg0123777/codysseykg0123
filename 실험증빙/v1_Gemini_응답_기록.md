# v1 모델 응답 기록

- 실험: v1 (Zero-shot 기본 프롬프트), Case A/B/C
- 자료 출처: 사용자가 Gemini 실험 후 이 대화에 붙여넣은 출력
- 입력 방식: 웹 UI, 단일 메시지로 3개 Case 입력
- 실제 실행 시각/모델 화면 증빙: 미수집
- 본 파일은 **응답 기록**이며, 최종 제출물의 10턴 연속 대화 로그와 별개다.

## CASE A. 캠퍼스 통학 환경 개선 프로젝트

### 1. 과제 요약

* **목적:** 대학생 최소 60명 대상 설문조사 데이터를 분석하여 실현 가능한 통학 환경 개선안 제시
* **핵심 분석 내용:** 주요 통학 수단, 평균 통학 시간, 주요 불편사항
* **핵심 요구사항:** 데이터 시각화 3개 이상, 개선안 2개 이상(실현 가능성 검토 포함), 참고자료 2개 이상

### 2. 최종 제출물

1. **분석 보고서 PDF** (최대 6페이지, 한계점 및 결론 포함)
2. **정제된 설문 데이터 CSV** (개인식별정보 제거 필수)
3. **발표자료 PPTX** (최대 8슬라이드, 핵심 분석 결과 및 개선안 2개 포함)
* *제출 방식:* ZIP 압축 없이 LMS에 3개 파일 개별 제출

### 3. 실행 체크리스트

* [ ] 설문 데이터 정제 (이름, 연락처 등 개인식별정보 삭제)
* [ ] 나머지 데이터 시각화 2개 이상 추가 작성
* [ ] 데이터 시각화별 해석 작성
* [ ] 통학 환경 개선안 2개 도출 및 실현 가능성 검토
* [ ] 분석 보고서 PDF 작성 (최대 6페이지, 참고자료 2개 이상 포함)
* [ ] 발표자료 PPTX 작성 (최대 8슬라이드)
* [ ] LMS에 3개 파일 각각 업로드 점검 (2026-11-10 23:59 마감)

### 4. 추천 수행 순서

1. **데이터 전처리 및 개인정보 제거:** CSV 정제 완료
2. **시각화 확충 및 분석:** 추가 시각화 2개 작성 및 해석 도출
3. **개선안 도출:** 데이터 기반 개선안 2개 설계 및 실현 가능성 검토
4. **보고서 작성:** 6페이지 이내로 PDF 최종 완성
5. **발표자료 작성:** 보고서 핵심 내용을 8슬라이드 이내 PPTX로 요약
6. **최종 검토 및 개별 제출:** ZIP 압축 여부 확인 후 LMS 업로드

### 5. 누락 위험 요소

* CSV 파일 내 응답자 개인식별정보(이름, 연락처 등) 미제거로 인한 감점
* 세 파일을 ZIP으로 압축하여 제출하는 실수 (개별 제출 원칙)
* 보고서 분량 초과(6페이지 초과) 또는 슬라이드 수 초과(8슬라이드 초과)
* 참고자료 수 미달(최소 2개 미만) 또는 시각화 수 미달(최소 3개 미만)

### 6. 확인 필요 사항

* 현재 작성된 시각화 1개가 보고서 규격 및 분석 주제에 부합하는지 재확인

### 7. CASE A 검증 질문 답변

* **Q1.** 최종 제출물은 총 **3개**이며, **① 분석 보고서 PDF, ② 정제된 설문 데이터 CSV, ③ 발표자료 PPTX** 입니다.
* **Q2.**
* **완료된 작업:** 설문 응답 65명 확보, 주요 통학 수단 관련 시각화 1개 작성
* **앞으로 수행할 작업:** 설문 데이터 전처리(개인정보 제거), 추가 시각화 2개 이상 작성 및 해석, 개선안 도출 및 검토, 분석 보고서 PDF 작성, 발표자료 PPTX 작성

* **Q3.**
* **제출 마감일:** 2026년 11월 10일 23:59
* **제출 방식:** ZIP 압축을 하지 않고 LMS에 세 개 파일을 각각 제출

## CASE B. 생성형 AI의 사회적 영향 분석

### 1. 과제 요약

* **목적:** 생성형 AI가 사회에 미치는 영향을 분석하는 개인 보고서 작성
* **핵심 요구사항:** 서로 다른 사회적 쟁점 2개 이상, 쟁점별 이해관계자 2개 집단 이상 입장 비교, 본인 주장 및 근거 제시, 반대 의견 1개 이상 및 재반박 포함, 신뢰할 수 있는 참고자료 3개 이상

### 2. 최종 제출물

* **공식 확정 제출물:** 생성형 AI 사회적 영향 분석 보고서 (A4 2~3페이지 권장)
* **제출 파일 형식/제출처:** 추후 별도 공지 예정

### 3. 실행 체크리스트

* [ ] 사회적 쟁점 2개 선정 및 이해관계자 각 2개 집단 정의
* [ ] 참고자료 3개 이상 수집 및 분석
* [ ] 반대 의견 1개 및 이에 대한 재반박 논리 구성
* [ ] 보고서 초안 작성 (A4 2~3페이지 권장)
* [ ] 교수자/학교의 공식 추가 공지 확인 (마감일, 제출처, 파일 형식, 발표 여부)

### 4. 추천 수행 순서

1. **공식 공지 지속 확인:** 마감일 및 추가 제출물(PPT 등) 여부 채널 확인
2. **주제 및 자료 수집:** 쟁점 2개 선정 및 신뢰할 수 있는 참고자료 3개 확보
3. **논리 구성:** 이해관계자 비교 + 본인 주장 + 반대 의견 및 재반박 구조화
4. **보고서 작성:** 권장 분량(A4 2~3페이지)에 맞춰 보고서 완성

### 5. 누락 위험 요소

* 비공식 정보(친구의 말)만 믿고 공식 제출처 및 마감일을 오인하여 제출 기한을 놓칠 위험
* 이해관계자 비교, 반대 의견/재반박, 참고자료 수(3개) 등 핵심 구조 요소 누락

### 6. 확인 필요 사항

* **[확인 필요]** 최종 제출 마감일 및 제출처
* **[확인 필요]** 제출 파일 형식(PDF, DOCX 등)
* **[확인 필요]** 발표자료(PPT) 작성 및 제출 여부 (비공식 메모 검증 필요)

### 7. CASE B 검증 질문 답변

* **Q1.** **확정할 수 없습니다.** 마감일 10월 25일은 친구의 비공식 메모일 뿐이며, 공식 과제 공지에서는 제출 마감일을 추후 안내한다고 명시되어 있습니다.
* **Q2.** **아닙니다.** 발표 관련 사항은 추후 별도 공지 예정이며, PPT 필수 제출 여부는 공식적으로 확인되지 않았습니다.
* **Q3.** **아닙니다.** 3페이지로 고정된 것이 아니라 **A4 2~3페이지 권장** 사항입니다.

## CASE C. 캠퍼스 안전 데이터 분석

### 1. 과제 요약

* **목적:** 학교 안전 관련 데이터 1개를 분석하고 개선 제안 작성
* **핵심 요구사항:** 데이터 출처 명시, 시각화 최소 2개, 분석 결론 및 안전 개선 제안 포함

### 2. 최종 제출물

* **분석 보고서 PDF** (최대 4페이지)
* **원자료 CSV**
* *주요 확인 사항:* 마감일 정보 충돌 및 비공식 발표 영상 요구사항 확인 필요

### 3. 실행 체크리스트

* [ ] 데이터 분석 및 시각화 2개 이상 작성
* [ ] 안전 개선 제안 및 결론 도출
* [ ] 분석 보고서 PDF 작성 (최대 4페이지, 출처 표기)
* [ ] 마감일 공식 재확인 (공지 11/13 vs 평가기준 11/14)
* [ ] 발표 영상 제출 여부 교수자 문의 확인

### 4. 추천 수행 순서

1. **공시 정보 확인 문의:** 교수자/LMS Q&A를 통해 마감일 충돌 및 발표 영상 필수 여부 문의
2. **안전 데이터 분석:** 수집된 안전 데이터 시각화(2개 이상) 및 해석
3. **개선 제안 작성:** 데이터 기반 안전 개선안 도출
4. **보고서 완성 및 CSV 정리:** 최대 4페이지 PDF 완성 및 원자료 준비
5. **조기 제출:** 안전하게 1차 공지 마감일(11/13 18:00) 이전에 제출 완료

### 5. 누락 위험 요소

* 평가기준일(11/14)만 믿고 있다가 공지 마감일(11/13) 초과로 미제출 처리될 위험
* 친구 메모의 발표 영상을 확인 없이 제출물에서 제외했다가 감점될 위험(또는 불필요한 작업 수행)

### 6. 확인 필요 사항

* **[확인 필요]** 정확한 최종 마감일 (공시 공지: 2026-11-13 18:00 vs 평가 기준: 2026-11-14 18:00)
* **[확인 필요]** 발표 영상 제출의 공식 필수 여부

### 7. CASE C 검증 질문 답변

* **Q1.** **확정할 수 없습니다.** 공식 공지사항에는 2026-11-13 18:00으로 되어 있으나, 공식 평가 기준에는 2026-11-14 18:00으로 명시되어 있어 **정보가 서로 충돌**합니다. 교수자 확인이 필요하며, 안전을 위해 11월 13일 18:00을 목표로 진행하는 것이 바람직합니다.
* **Q2.** **아닙니다.** 공식 제출물은 보고서 PDF와 원자료 CSV이며, 발표 영상은 친구를 통해 들은 비공식 메모이므로 공식 필수 제출물인지 확인이 필요합니다.
* **Q3.**
* **완료된 작업:** 안전 데이터 수집 완료
* **추가 확인 필요 사항:** 정확한 마감일(11/13 vs 11/14) 확정, 발표 영상 제출 필요 여부
