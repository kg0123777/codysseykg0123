**실험 방식:** 동일한 Gemini 웹 대화의 시작 메시지로 02 보고서의 v2.1 역할 지시를 제공하고, 이후 사용자 과제 입력 10개에 대해 각각 Gemini 응답을 얻음. 위 '응답 전문'은 실험자가 복사해 ChatGPT에 제공한 원문을 보존한 것이다. Gemini 자체 공유 링크나 UI 스크린샷, 실시간 실행 로그 메타데이터가 있다는 뜻은 아님.

## 주요 관찰

- Gemini는 PPTX 폐지→XLSX 추가, 평가 총점 100점 유지, 공식 자료 간 마감일 충돌(12/02·12/04), 비공식 소문 분리에 성공.
- **완료 상태 누락:** Turn 3~8에서 명시적 완료 작업 7개 중 체크리스트 `[x]`는 5개만 출력. Turn 9·10에서 7개 전부 복원.
- **근거 부족 위험:** ZIP 제출의 구체적인 감점 결과를 추정했고, LMS 재제출 허용 여부를 확인하지 않은 상태에서 재제출을 권고함.
- 최종 v2.1은 실험을 거쳤지만 무결성이 입증된 것은 아니며, 후속 v2.2 개선 제안은 아직 검증하지 않음.
